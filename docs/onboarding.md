# Onboarding

1. Installer Node.js 20 et pnpm.
2. Copier `.env.example` vers `.env.local`.
3. Installer les dépendances avec `pnpm install`.
4. Lancer le projet avec `pnpm dev`.
5. Vérifier lint, typecheck et build avant toute PR.

Le dashboard est accessible à la racine et fonctionne sans clé fournisseur pour le mode démonstration.
