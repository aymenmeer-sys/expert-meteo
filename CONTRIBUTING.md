# Contribuer

Créer une branche `feature/*`, `fix/*` ou `chore/*`, utiliser Conventional Commits, ajouter les tests associés et ouvrir une PR vers `develop`. Toute PR doit documenter le contexte, les changements, les tests et les risques.

Les secrets ne doivent jamais être commités. Les checks CI requis sont lint, typecheck, tests et build.
