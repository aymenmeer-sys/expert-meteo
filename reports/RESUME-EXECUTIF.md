# Résumé exécutif

MétéoExpert dispose d'un dashboard météo professionnel en français, responsive et accessible, centré sur la météo actuelle, les prévisions horaires et les prévisions à cinq jours. L'expérience comprend une recherche de villes, un sélecteur d'unités, les favoris, les indicateurs de qualité de l'air et une carte de précipitations.

Le socle est prêt pour l'industrialisation : CI, documentation, sécurité, observabilité et intégrations API sont cadrées dans la roadmap. Les mesures de production et la release GitHub nécessitent un runner CI et des permissions d'écriture sur le dépôt `aymenmeer-sys/expert-meteo`.
